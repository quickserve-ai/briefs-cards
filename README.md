# briefs-cards

Public link-preview cards for the org-gated WithQ Briefs site.

The briefs site sits behind GitHub org auth, so unfurl bots (Slack, iMessage,
Twitter…) can't read it and show a generic GitHub login preview. Each card here
is a small PUBLIC page (`<slug>.html` + `<slug>.png`) carrying the Open Graph
tags for one brief and instantly redirecting human visitors to the gated brief.

**Share the card URL, not the gated URL**, when you want a rich preview.

Everything in this repo is world-readable: card titles and descriptions must
pass a public-grade redaction bar (no customer identifiers, deal economics, or
PII). Cards are generated by the `/brief` skill's `scripts/og_cards_sync.py`
(which renders through `scripts/og_card.py`). Cards are DEFAULT-ON for every
brief routed to the org surface; a brief whose title or URL slug cannot pass
the public bar gets no card (it keeps its gated URL as its only link), and a
re-sync removes the card of any brief that is later skipped or unrouted.
Do not hand-edit cards here — the next sync overwrites or prunes them.
